澳洲房产数据 API 对比摘要

来源:13Labs《Australian Property Data APIs Compared》(2026-07-29)。临时摘要页,非原文。
原文链接

核心结论:四家(Domain、Pricefinder、PropTrack、Cotality)都不公开 API 价格;只有 Domain 可自助申请 key。其余三家需通过客户经理/合同,项目第一步是销售沟通而非写代码。

四家对比

提供方文档获取方式公开 API 价格
Domain Developer API公开门户 + 沙盒自助建项目拿 key无
Pricefinder公开 Swagger仅客户经理无
PropTrack公开 Stoplight 门户仅客户经理无
Cotality(原 CoreLogic)需登录(401)仅合同无

所有权

  • CoStar 于 2025-08-27 完成收购 Domain Holdings(企业价值约 A$30 亿),因此同时拥有 Domain API 与 Pricefinder。
  • CoreLogic 于 2025-03-24 全球更名 Cotality;澳洲主体仍为 RP Data Pty Ltd。
  • PropTrack 属 REA Group(realestate.com.au 运营方)。实质是 CoStar、Cotality、REA 三家。

Domain

  • 13 个 API 包:地址建议、房源、房产、估价、租金 AVM、学校、Webhooks 等。
  • 唯一公布限流:1,000–3,000 次/分钟(视套餐);每日配额于 AEST 10am 重置;超限返回 429。
  • SLA:月可用性 99%,P95 响应 <900ms;责任上限 AUD 5,000。
  • 价格:按合同 Product Schedule(AUD、不含 GST),按行业与月调用量分档。
Domain 条款的限制:
  • 7.6(d) 不得转售/分发给第三方
  • 7.6(g) 不得做衍生作品
  • 7.6(j) 数据不得在澳洲境外存储/使用(须境内托管)
  • 7.6(k) 不得用于任何直接营销(如屋主开发)
  • 16.5 终止后须删除缓存数据,可被审计
  • 17.1 基于其房源的页面须 no-index、标注 Powered by Domain、回传事件 → 无法做程序化 SEO

Pricefinder

  • Swagger 公开:v1.13.1,112 个路径、188 个 schema、19 个标签,OAuth2。
  • 功能:可比成交搜索、多边形搜索、AVM(售价/租金/收益率)、CMA PDF、SSO 跳转。
  • 多数集成需用终端用户自己的付费 Pricefinder 账号认证;不可商业化再分发。
  • 唯一公开价格是网页版席位价:A$175+GST/月(合作页折扣价 $90+GST),并非 API 价格。
  • Rex、SalesTrekker、Realtair 等集成均需每个经纪自购席位;数据不得用于直接营销。

PropTrack

  • 公开 developer.proptrack.com.au:地址匹配、房产摘要/属性、成交、估价、市场供需、人口统计、报告 PDF 等。
  • 无自助 key、无公开价格、无免费层;试用范围由客户经理决定。
  • 收费模式(ACCC 文件):订阅或按用量,含阶梯折扣。
  • 是获取 realestate.com.au 衍生数据的合法途径。

Cotality

  • 最封闭:连 API 目录都需登录;试用需有效 ABN 并经批准。
  • 宣传产品:Commercial API(600+ 数据点)、Cordell Construction API、AVM(覆盖 96% 住宅)、租金 AVM(97%)、Propensity to List、Property Monitor(均为厂商自述)。
  • 终端条款最严:禁转售、禁抓取、禁并入其他产品;终止后须归还/销毁;适用新州法律。
  • 无澳洲公开价格页。

realestate.com.au

  • 可通过 REAXML 免费推送房源;没有公开的数据拉取 API。
  • 条款禁止任何自动化抓取;robots.txt 禁止所有主流 AI 爬虫(仅允许 Applebot)。
  • REA 曾起诉 Domain(2024-12 报道):指控 181 条独家房源被抓取并出现在 Pricefinder;截至 2026-07-29 结果未能核实。

价格与调用量挂钩,调用量取决于架构(如按页面浏览调用会很贵),设计前应书面询价。

建议

  1. 想立刻原型验证 → 用 Domain 沙盒,但先核对其条款(境内托管、不可转售、不可营销、不可做 SEO)。
  2. 需要 realestate.com.au 数据 → 走 PropTrack,不要抓取。
  3. CRM 集成 → 评估用户群里已付费 Pricefinder 席位的占比。
  4. 先书面确认 API 权限与使用权,再定架构。
